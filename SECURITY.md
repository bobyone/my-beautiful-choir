# Security policy

## Supported versions

my-beautiful-choir has not been released yet. Once released, security fixes
are provided for the latest minor version only.

| Version | Supported |
|---|---|
| `main` (unreleased) | yes |

## Reporting a vulnerability

**Never report a vulnerability in a public issue, discussion or pull
request.**

Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/bobyone/my-beautiful-choir/security/advisories/new).

Include, when possible:

- the affected version or commit;
- the mode concerned (web mode or personal mode);
- the steps to reproduce, and the impact you observed;
- any log excerpt, with secrets and personal data removed.

You will receive an acknowledgement within 7 days. The fix is prepared in a
private advisory, released, then the advisory is published with credit to
the reporter, unless they prefer to remain anonymous.
